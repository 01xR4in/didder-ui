    Algorithm
    -0.5 / 0.5 is the recommended default. Narrow the range to reduce noise; skew it to bias light or dark.
    Palette -p
    Accepts #rrggbb, rrggbb, #rgb, r,g,b, 0–255 gray, or SVG names like forestGreen.
    This didder build predates mmcq:N (added after v1.3.0), so it is disabled. See the README to build from the pinned main commit.
    Recolor -r ?
    Also accepts RGBA tuples like 0,0,0,0 to make a colour transparent. Must have the same number of colours as the palette.

    Strength -s Try ~64% for bayer/odm on colour images, ~80% to reduce edm noise.
